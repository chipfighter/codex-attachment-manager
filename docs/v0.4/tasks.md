## G04-1：核心可行性

- [ ] **T04-01 历史图片取消/恢复与思考兼容**。依赖 T04-00。
  - 模型用 Haiku 5.5（用户 2026-10-10 定），思考用 Claude Code 的默认配置，先确认请求里确有思考块；运行次数在开始前与用户确认。
  - 用合成图 A、B 和一份重复出现，在同一桌面订阅会话中完成上传、看图、取消 A、继续对话、恢复 A、再继续；覆盖工具图片和实际出现过思考块的历史。
  - 确认本地出现记录与发出的图片块能够可靠对齐；同时检查被取消图确实未发、未取消图保留、恢复图回到应有位置。
  - 用最小取回工具在本轮提供原图、下一轮用实验改写省略副本，检查思考兼容；不要求先实现 T04-08 的完整自动模式。
  - 思考块原样转发。记录：账号放行还是返回 400；加 beta 头 `thinking-binding-controls-2026-08-01` 并设 `prefix_mismatch_behavior: "error"` 模拟新账号的结果；订阅链路是否接受该 beta 头；被拒后原样重发能否接上，Claude Code 自己怎么处理 400。没有实际思考块的文本测试不能覆盖签名约束。beta 头和诊断参数只用于实验，不加入正式请求。
  - 上下文管理说明用 `role: "system"` 放在第一张被省略的图所在那条用户消息之后，验证订阅链路接受、模型不收回之前的回答；先做最小改写，不提前搬整套引擎。
  - 关联：R04-02、R04-05；A04-02、A04-03、A04-04 的 G04-1 子集、A04-09。通过本任务不勾整项 A04-04。
  - 证据：本机脱敏请求差异、回应状态、只读检查、合成图的模型回答；失败时保存根因与选项。

## G04-2：正式手动模式

- [ ] **T04-03 Claude 接入与运行入口**。依赖 T04-02a。
  - 照原机制：Claude 插件带 MCP 服务（与 Codex 共用 `plugin/src`），由它拉起并看守引擎；Mod 只负责切地址，先确认引擎就绪再切，保存并恢复原值。确定 Claude 插件的目录与清单、MCP 服务在 Claude 下的 Node 运行环境和安装副本检查。
  - Codex 和 Claude 共用一个引擎：现在引擎在没有 Codex 进程时自己退出（`engine.ts` 的 `watchForCodex`），要改成两边都不在用时才退出；替换规则要避免两份插件副本版本相同、代码不同时来回让对方的引擎退役。改的是共用代码，改完重新 `cam install`，确认 Codex 照常能连上。
  - 覆盖 HTTP 查询、认证、系统代理、SSE、上游错误、取消；无改写路径保持原始正文。
  - 关联：R04-01、R04-07；A04-01、A04-02、A04-10、A04-11。
  - 证据：回归测试和真实桌面订阅冒烟；不以实验插件代替正式包。

- [ ] **T04-04 会话索引与图片出现记录**。依赖 T04-02a。
  - 照原机制从 Claude Code 的本地会话记录只读、增量地找图和编号，引擎和插件服务各自计算；稳定编号、轮次、尺寸、重复关系与来源；处理直接图、工具图和取回副本。会话按 `x-claude-code-session-id` 认出。
  - 对齐按原机制的顺序：工具图用 `tool_use_id`，用户图用类型、轮次和内容哈希；核对历史预处理与发送块的差异；状态按客户端和会话隔离，未知结构保留。
  - 关联：R04-02、R04-03；A04-03、A04-05、A04-09。
  - 证据：合成 fixtures 的单元测试，真实桌面只读核对；提交中不含真实会话样本。

- [ ] **T04-05 Claude 手动请求改写**。依赖 T04-03、T04-04。
  - 只替换确定的授权图片，保留消息/工具结构与其余字段；普通/重复占位符、已提供标签、中英文照原机制实现，上下文管理说明用 `role: "system"` 放在那条用户消息之后；思考块原样转发，被拒时原样重发并提示。
  - 选择不变时改写稳定；无法安全改写时原样转发并给出可见原因，回退不算取消成功。
  - 关联：R04-02、R04-06；A04-02、A04-03、A04-04、A04-09。
  - 证据：先失败再通过的单元测试、请求差异、同会话桌面取消/恢复及双语模型自测。

- [ ] **T04-06 续聊、分叉与多会话**。依赖 T04-04、T04-05。
  - 识别当前会话变更、续聊、分叉与子代理；保留编号，按分叉时点继承并分别管理。压缩（`/compact` 与自动压缩）和 `/rewind` 回退之后，已有编号不变、选择不串。
  - 不只依赖 `session.start` 更新会话状态；核对真实事件时序。
  - 关联：R04-03；A04-05、A04-10。
  - 证据：两会话隔离、重载、续聊、分叉、压缩、回退、工具中间请求的回归与桌面记录。

- [ ] **T04-07 完整手动面板**。依赖 T04-02、T04-04、T04-05。
  - 接入完整列表、预览、整轮勾选、来源筛选、发送预估/实际统计、需要编号定位、任务名、刷新、启停、主题和双语。
  - 逐项引用现行 v0.3 的行为；筛选不改变发送，整轮选择按显示项处理。走 MCP 应用时复用 `panel.html`；走 Mod 面板时，做不到的项先列给用户确认。
  - 关联：R04-04、R04-06；A04-06、A04-07。
  - 证据：交互检查、双语截图、用户在关键节点的反馈；接口差异与降级不能隐瞒。

## G04-3：自动模式

- [ ] **T04-08 自动选图与原图工具**。依赖 T04-05、T04-06、T04-07；先确认 T04-01 覆盖取图副本省略。
  - 自动开关默认关；旧图省略、新图照常、固定发送与手动状态分开；模型按编号真正取到图片，副本仅在本轮提供。取图工具由插件的 MCP 服务提供，始终注册、不随开关增删。
  - 取回不另编号、不改用户勾选；下一轮省略副本，前面的占位文本保持稳定；关闭自动恢复手动状态。
  - 关联：R04-05；A04-04、A04-08。
  - 证据：带随机标记的合成图测试，工具图回传和后续请求检查，中英文该取/不该取测试。
