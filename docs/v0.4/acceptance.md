# v0.4 验收标准

> 状态：待执行的增量验收。方案见 [plan.md](plan.md)，执行见 [tasks.md](tasks.md)。现行 v0.3 行为引用 [spec.md](../spec.md)，不另定义一套行为。
> 必须区分：本机模拟、终端、真实桌面订阅、用户界面确认。前者通过不能自动替代后者。

## A04-01 官方订阅接入

真实 Claude 桌面 Code 的本地会话，保持官方订阅登录，不填 API key、不换账号。正式安装后无需手改配置，启用后请求经本机引擎到 Anthropic，回复完整；停用后恢复原始地址。

检查 OAuth capability 与认证透传、无意外 API key，以及实际安装副本和会话加载。原样文本探针已通过的是入口部分；正式安装、自动启动与恢复仍待验。

## A04-02 无选择变化时原样发送

没有取消项、自动模式未使用时，转发的请求正文与原始正文逐字节一致。必要的 HTTP 传输头处理单独比较；认证、版本和 beta 保留。错误状态/正文、查询串与 SSE 完整透传，取消客户端请求时上游结束。

图片不需要替换时，不重排消息、不重编码图片、不增加占位说明、不改工具调用或思考块。

## A04-03 同一会话取消与恢复

用合成图 A、B 和 A 的重复出现，先确认模型看到它们，再取消指定出现记录并继续同一个会话：

1. 下一次请求中只有指定目标变成正确占位符，其他图仍在。
2. 普通与重复占位符按本次仍发送的图决定，不因同内容而合并用户选择。
3. 重新勾选后，下一次请求恢复对应原图，模型可以读取测试标记；不另开会话或重建历史。
4. 新出现图按现行手动规则默认发送；选择不变时改写结果稳定。
5. 原始素材与已有历史保持只读，按 A04-09 取证。

同时检查用户图和工具结果图，不能只凭模型说“看不到”证明图片已删，必须检查发出的请求。

## A04-04 思考兼容与模型行为

**G04-1 前置子集**：模型用 Haiku 5.5，运行次数先与用户确认。在真实桌面订阅、正常使用的思考配置下，历史中确实已有思考块后执行 A04-03，并用最小工具取回实验覆盖工具图及取回副本下一轮省略；不要求先完成完整自动模式。

- 账号放行时，改写后的请求正常完成，模型按 A04-03 的要求回答。账号拒绝（400）时，包括用 `prefix_mismatch_behavior: "error"` 模拟的新账号，引擎原样重发、对话不断，面板提示这次没能按勾选改写，且不计入取消成功。记录真实模型、思考配置、账号表现及请求诊断。
- 引擎不删思考块、不加 `drop_block`、不关思考。若有必要取舍，记录影响与可复现证据，经用户确认并修改规格后再改验收；当前不默认接受。
- 未修改图片的文本往返、没有实际思考块的测试不能证明兼容；用户账号放行之外，必须再测一次模拟新账号的拒绝路径。官方文档不能替代桌面订阅实测。

**正式模型行为验收**：T04-05 覆盖手动模式，T04-08 覆盖完整自动模式。模型不收回之前看原图的有效描述，不补充现在看不到的新细节；手动按编号要图、恢复后能看图；自动模式该取图时取，不需要时不取。专项自测覆盖中英文，模型范围与成本上限先确定；Codex 的 GPT 自测不能代替它。

G04-1 只记录前置子集通过，不提前勾整项 A04-04；正式模型行为和思考兼容均通过后，此项才算完成。

## A04-05 索引、来源与编号

能按时间/轮次列出客户端实际支持的用户上传、工具查看/返回和生成图片的每次出现，展示稳定编号、名称、尺寸、大小和可靠来源。字节/像素相同的重复关系按现行规则判断；同图每次出现仍独立编号。

继续会话、重新打开、插件重载后编号不乱。模型取回的副本不增加新的素材行。认不准的来源不猜，Claude 没有的 Codex 专属来源不伪造；无法安全对应的图片保留并提示原因。

## A04-06 桌面内面板（前置关卡）

在真实 Code 界面中显示多张真实缩略图，能放大预览、单张勾选、保存与当前会话对应，操作无需模型参与。用户自己输入 `/cam`，面板在 Claude 桌面自带的浏览器里打开，不要求模型帮忙打开（D04-04）。

接口声明、示意图、终端界面或外部浏览器开发页均不能替代桌面内验收。关键节点由 Claude 截图检查并交用户反馈，反馈未解决时不勾完成。

## A04-07 完整交互与双语

按现行规格逐项检查：整轮勾选、来源筛选、编号定位、发送预览/上一次实际统计、任务名、自动刷新、预览、启停、主题和中英文文字。

筛选只影响显示；整轮选择只作用于该轮显示项；跳转隐藏项时按现行规则显示和定位。预估明确标为预估，不把请求大小或图片数量等同于已节省的模型 token。实际无法改写时在面板提示原因。

## A04-08 自动选图

默认关，任务各管各的。开启后按现行 v0.3 语义：历史未固定图省略、本轮新图照常、固定图每轮发；手动勾选与固定发送分开保存。

模型按 IMG 编号取到原图，实际读出合成图随机标记；这份副本仅在本轮提供，下一轮不再发送，原位置占位符和前面的历史文本保持稳定。副本不另占列表行，不改变用户勾选或开关。面板显示最近取回编号和行标记；关闭自动后手动选择恢复。

覆盖中英文的需要图/不需要图场景，并通过 A04-04 的思考兼容检查。工具注册或返回一段 base64 文本不算模型已看到图。

## A04-09 原始数据只读与隐私

原始素材前后哈希不变；选择操作不改已有会话历史。对正在继续的会话，核对原有历史前缀或静态快照不变，并区分 Claude 自身正常追加记录，不能把官方追加误算成插件改写。

插件只写工具数据目录和自管安装配置；恢复不覆盖用户其他设置。日志不含认证值、原始图片和聊天正文，真实证据只在 `local/` 或工具数据目录。提交只含合成/脱敏样例，无用户具体路径和私有会话标识。

## A04-10 生命周期、隔离与失败恢复

验证两个同时运行的会话、继续/分叉、子代理、压缩与回退、重载、桌面重启、服务失败、停用/卸载、登录刷新和插件更新，以及只开 Claude 不开 Codex、两边同时使用同一个引擎。不会串勾选状态，不覆盖其他服务地址，不留下指向已停止服务的配置；只开 Claude 时引擎不因没有 Codex 进程而退出，两份插件副本不来回让对方的引擎退役。启用前服务就绪，恢复后真实请求可直连正常回答。

未识别、无法解析或不能安全改写的请求原样发送并提示原因；不静默发送后宣称已取消，也不把回退计入 A04-03/A04-08 的成功次数。自动恢复和平台限制按实测范围如实说明。

## A04-11 Codex 回归

现有 v0.1–v0.3 的相关单元、自测、安装/卸载冒烟通过；无取消、手动和自动模式语义不变。共享运行代码或文字修改时，按 AGENTS.md 跑对应自测并重新安装，验证实际安装副本。

Windows 优先。macOS/Linux 的 CI 与桌面实测分别记录，不将“CI 能启动”写成“桌面功能全通过”。

## A04-12 交付与证据

每项验收有对应任务、执行环境、最后相关改动后的结果、证据位置和审阅结论。界面关键节点与最终用户验收有反馈记录；全部通过后才更新正式支持声明和发布。

由 Claude 将确认结果更新到现行规格和方案，保持当前事实与版本一致。英文 README/CHANGELOG、中文说明与实际能力一致，不以本机探针或 API key 模式冒充官方订阅完整支持。
